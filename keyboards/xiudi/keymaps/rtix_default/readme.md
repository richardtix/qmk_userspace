# ENG/HU keymap for XD60

An updated keymap brought up to speed with 2026 keycodes in QMK. Compiles with QMK CLI as of 2026/10/24.

Purpose of keymap:

- Reliably accomodate dual ENG/HU use.
- Primary layout and focus is ENG with some HUN mods on layer 1.
- Placed zero on layer1 ESC position to accomodate HUN numeral typing.

## Quick flash recap on Windows

1. Set up QMK CLI.
2. qmk compile
3. Install QMK toolbox
4. Install bootloader drivers if needed
5. Load resulting .hex file from QMK root
6. Flash.
